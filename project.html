// Overview

This project was built to connect industrial production systems with a custom software layer capable of synchronizing data, visualizing machine states and exposing information through a clear interface.

My work focused on backend architecture, real-time communication, Unity-based visualization and tooling for internal workflows.

Context

Industrial environment with the need to connect software, machines and production data in a reliable workflow.

My role

Backend development, Unity visualization, integration logic and technical decision-making.

Stack

Django, Unity 3D, C#, REST APIs, PLC integration and real-time data synchronization.
