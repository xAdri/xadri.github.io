Smart Tooling Intralogistics uses one detachable tablet and control system to operate trolleys, cranes and stackers while keeping every task synchronized.

Operator-centred HMI

The HMI is composed of two parts: a portable tablet that moves with the operator between machines, and a fixed display integrated into each machine.

When the tablet is placed in a machine’s dock, both elements work together as its local interface. The same portable control unit can therefore operate a trolley, crane or stacker while keeping the operator close to the equipment and in direct control of each movement.

ERP-connected task flow

The system integrates with each company’s existing ERP and presents the tasks assigned to each worker directly in the HMI. Operators can move from task guidance to machine control without switching to a separate application.

Actions performed on the trolley, crane or stacker update the shared task database, keeping pending work and completed operations aligned with both the ERP and the production floor.

Low-latency, safe operation

Communication latency stays between 180 and 220 milliseconds, keeping the machine response immediate enough for direct, deliberate operation across the different types of equipment.

A robust interlocking safety system blocks incompatible or unsafe actions to prevent failures and reduce human error, while keeping the operator in control of every valid movement.

From request to delivery

The workflow links tool selection, inventory, transport and delivery as one continuous process. As the operator completes each action, the system updates the database and advances the tasks that still need to be performed.

This keeps the digital workflow synchronized with the real machinery without taking control away from the person operating it.
