Smart Tooling Intralogistics

One interface across every machine

The setup has two parts. Operators carry a tablet from one machine to another, while each machine keeps its own fixed screen.

When they dock the tablet, both screens work together. They can control a trolley, crane or stacker while staying close to the equipment and seeing exactly what it is doing.

Low latency and safe control

Commands reach the machinery in 180 to 220 milliseconds, so the controls feel responsive and predictable across every type of equipment.

A safety system checks every action in the background. If a movement could cause a conflict or put the operation at risk, the machine simply will not carry it out.

CRM synchronized task workflow

The CRM assigns a task to an operator and sends it to the HMI. From there, the same task record moves through tool selection, inventory validation, transport and delivery, with every step writing its status back to the shared database.

The HMI and CRM always work with the same workflow state, so pending and completed operations remain synchronized in real time. When the operator confirms the final action on the machinery, the task is closed in the CRM and recorded as completed.
